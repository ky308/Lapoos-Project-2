KCC CREATIVE SCHOOL WEBSITE TEMPLATE

This version uses a different editorial layout: warm cream background, coral and teal accents,
large serif headlines, rounded/arched hero photo, numbered content blocks, and an asymmetric
grid. It is intentionally different from a standard blue-and-gold school template.

Files:
index.html, about.html, contact.html, course-details.html, courses.html, events.html,
pricing.html, starter-page.html, trainers.html
assets/css/style.css
assets/js/script.js
assets/images/

To run:
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open index.html with Live Server.

Customize:
- School details, official mission/vision, program names, event dates, and contact information.
- Replace sample photos with your own images.
- CSS is centralized in assets/css/style.css.
- Mobile menu and demo contact form behavior are in assets/js/script.js.

The sample school information and photos are placeholders. Verify official details before publishing.
